## Turing Test
**The Turing Test**, originally called the **Imitation Game** was proposed by **Alan Turing(1950)**, was designed to check if a machine can exhibit human level intelligence and qualify as an AI. The test is designed to check if the computer is indistinguishable from a human and in the case that it is, it can be considered an AI.

The computer needs the following capabilites:
 * Natural Language Processing (ability to communicate)
 * Knowledge Representation (ability to store knowledge; ie what it already knows or new information)
 * Automated Reasoning (ability to answer questions, draw conclusions based on what it knows)
 * Machine Learning(ability to adapt to new circumstances and also seek and extrapolate patterns)
 * Computer vision ( ability to perceive the environment, uses sensors)
 * Robotics (ability to interact with the enviroment, uses actuators)





### Test Setup and Methodology
In its most basic form, the test can be conducted in an isolated room where the interrogator communicates with the machine via text interface and if the interrogator can't distinguish the computer from a human, it passes **The Turing Test**. 


This means that a simple hardcoded program that can check for specific strings in your questions and respond to your questions seemingly like a human can easily pass the test and qualify as an AI.

## Why does it not require physical presence?
Its important to note that the test deliberately excludes physical interaction between the interogator and the subjects. This is because the simulation of a human isn't necessary to check the intelligence of the machine, therefore pysical presence can be considered obsolete for this experiment.

### Artificial Intelligence (AI):
Artificial intelligence (AI) is a set of technologies that empowers computers to learn, reason, and perform a variety of advanced tasks in ways that used to require human intelligence, such as understanding language, analyzing data, and even providing helpful suggestions.

### Machine Learning (ML):
Machine learning is a subset of Artificial Intelligence (AI) where computers learn from data and make predictions without being explicitly programmed. Instead of following hard-coded rules, ML algorithms analyze large datasets to find patterns and improve their accuracy over time


### Deep Learning (DL):
Deep Learning is a subset of machine learning that uses artificial neural networks with many layers to automatically learn complex patterns from large datasets. Unlike traditional ML, it can extract features on its own making it useful for handling unstructured data such as images, speech and text.

### Generative AI (GenAI)
Generative AI is a subset of Deep Learning which, as the name suggests, is capable of generating completely new data from the existing data. Its useful for LLMs, Image generation and Video or Audio generations.


### Data Science:
Data science is an interdisciplinary field focused on extracting knowledge from typically large data sets and applying the knowledge from that data to solve problems in other application domains. Its not a strict subset of AI but more of an overlapping set thats prerequisite to building AI systems.
